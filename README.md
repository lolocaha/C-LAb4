Задача 1

Составить программу, которая в списке L заменяет первое вхождение списка L1 (если такое есть) на список L2.

Алгоритм решения
Если L1 равен null или пуст, метод завершается.
Внешним циклом i от 0 до L.Count - L1.Count перебираются возможные позиции начала вхождения.
Внутренним циклом j элементы L[i + j] и L1[j] сравниваются через Equals. Если все элементы совпали, вхождение найдено, индекс i запоминается и поиск прекращается (заменяется только первое вхождение).
Если вхождение найдено, из L удаляется L1.Count элементов начиная с позиции i (RemoveRange), а на их место вставляется L2 (InsertRange).
Результат выводится на экран.

Задача 2

Сортировать элементы связного списка по возрастанию.

Алгоритм решения
Если список пуст, метод завершается.
Указатель curr ставится на первый узел.
Пока у curr есть следующий узел: если значение curr больше значения следующего узла, следующий узел переносится в начало списка, а curr возвращается на первый узел. Иначе curr переходит к следующему узлу.
Цикл заканчивается, когда за полный проход не найдено ни одной пары «левый больше правого», то есть список отсортирован.
Метод реализован для LinkedList<int>, LinkedList<char> и LinkedList<string> (строки сравниваются по алфавиту через string.Compare).
Отсортированный список выводится на экран.

Задача 3

Есть перечень компьютерных игр. Студенты группы играют в какие-либо из этих игр. Известно для каждого студента, в какие игры он играет.


Определить:

в какие игры играют все студенты;
в какие игры не играет ни один студент;
в какие игры играет ровно один студент.
Алгоритм решения

Данные хранятся в Dictionary<string, HashSet<string>> (студент и множество его игр) и в общем HashSet<string> со всем перечнем игр.

Играют все: копия перечня игр пересекается (IntersectWith) с множеством игр каждого студента.
Не играет никто: из копии перечня вычитаются (ExceptWith) множества игр всех студентов.
Играет ровно один: заводятся два множества once и many. Для каждой игры каждого студента: если игра уже есть в once, она добавляется в many, иначе в once. Результат: once минус many.
Все результаты выводятся на экран.

Задача 4

Дан текстовый файл. Определить, какие из букв «п», «ф», «к», «т», «ш», «с», «х», «ц», «ч», «щ» не встречаются в тексте.

Алгоритм решения
Создаётся HashSet<char> с перечисленными буквами.
Файл читается целиком (File.ReadAllText).

Если файл не найден, выводится сообщение об ошибке, и метод завершается.

Задача 5


На городской олимпиаде по информатике участникам было предложено выполнить 3 задания, каждое из которых оценивалось по 25-балльной шкале. Известно, что общее количество участников первого тура олимпиады не превосходит 250 человек. На вход программы подаются сведения о результатах олимпиады. В первой строке вводится количество участников N. Далее следуют N строк формата:

<Фамилия> <Имя> <Баллы>

Здесь <Фамилия> – строка, состоящая не более чем из 20 символов; <Имя> – строка, состоящая не более чем из 15 символов; <Баллы> – строка, содержащая три целых числа, разделённых пробелом, соответствующих баллам, полученным участником за каждое задание первого тура. Фамилия и имя, имя и баллы разделены одним пробелом.

Примеры входных строк:

Петрова Ольга 25 18 16
Калиниченко Иван 14 19 15

Написать программу, которая выводит на экран фамилию и имя участника, набравшего максимальное количество баллов. Если среди остальных участников есть набравшие такое же количество баллов, их фамилии и имена также следует вывести. Порядок вывода произвольный.

Алгоритм решения
Вводится N. Ввод повторяется, пока не будет введено целое число от 1 до 250.
Для каждого из N участников вводится строка. Вспомогательный метод проверяет формат: ровно 5 частей, фамилия не длиннее 20 символов, имя не длиннее 15, три балла являются целыми числами от 0 до 25. При ошибке ввод строки повторяется.
Считается сумма баллов участника.
Один проход с хранением текущего максимума max и списка лидеров: если сумма больше max, список очищается, в него добавляется участник, max обновляется. Если сумма равна max, участник добавляется в список.
После чтения всех участников выводятся фамилии и имена из списка лидеров.

Задачи 6-7

Создать класс Money (рубли и копейки) и перегрузить для него операции.

Унарные операции:

++ — добавление копейки к объекту типа Money;
-- — вычитание копейки из объекта типа Money.

Операции приведения типа:

uint (явная) — результатом является количество рублей (копейки отбрасываются);
double (неявная) — результатом являются копейки, переведённые в рубли, целые рубли отбрасываются, результат меньше 1.

Бинарные операции:

+ — Money m и беззнаковое целое число (лево- и правосторонние операции). Результат должен быть типа Money;
- — Money m и беззнаковое целое число (лево- и правосторонние операции). Результат должен быть типа Money.
Алгоритм решения
В классе два поля: рубли (uint) и копейки (byte). Доступ через свойства с явными get и set. В set копеек проверяется, что значение меньше 100, иначе выбрасывается ArgumentException.
Вспомогательные private-методы: ToKopeks переводит объект в общее число копеек (тип ulong, чтобы не было переполнения при умножении рублей на 100), FromKopeks переводит число копеек обратно в рубли (/ 100) и копейки (% 100).
Беззнаковое число в операциях + и - трактуется как количество копеек. Операции + и - переводят объект в копейки, выполняют действие и возвращают новый Money. Избыток копеек автоматически переходит в рубли.
uint - Money трактуется как «из N копеек вычесть сумму». Если результат вычитания получается отрицательным, выбрасывается InvalidOperationException.
++ и -- прибавляют и вычитают одну копейку. -- на нулевой сумме выбрасывает InvalidOperationException.
Явное приведение к uint возвращает рубли. Неявное приведение к double возвращает копейки / 100.0.
В Main выполняется автотест с известными значениями и проверка с вводом данных с клавиатуры. Ввод проверяется через uint.TryParse, копейки должны быть от 0 до 99. Операции вычитания обёрнуты в try/catch.
Вывод выполняется через ToString(), потому что из-за неявного приведения к double вызов Console.WriteLine от объекта Money выбрал бы перегрузку для double.
